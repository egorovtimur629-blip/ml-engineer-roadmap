## Техническое задание недели

Вход: список конечных чисел `int`/`float`. Проверка строк, `None`, `NaN`, бесконечности и других типов пока вне задания.

Выход: словарь с четырьмя ключами:

| Ключ | Значение |
|---|---|
| `count` | Количество элементов. |
| `min` | Наименьшее число. Для пустого списка `None`. |
| `max` | Наибольшее число. Для пустого списка `None`. |
| `mean` | Среднее арифметическое. Для пустого списка `None`. |

Пример входа: `[10, 20, 30, 40]`.

Ожидаемый результат:

```python
{"count": 4, "min": 10, "max": 40, "mean": 25.0}
```

Для `[]`:

```python
{"count": 0, "min": None, "max": None, "mean": None}
```

Требования:

- Функция возвращает результат и не изменяет входной список.
- Вычисление отделено от печати результата.
- Используются базовые возможности Python; внешние библиотеки не нужны.
- В первой версии можно использовать встроенные `len`, `sum`, `min`, `max`.
- Для защиты самостоятельно перепиши подсчёт суммы через цикл без `sum` и объясни, как избежать деления на ноль.
- Сохрани функцию в `stats.py`; добавь отдельный файл проверок и короткий README с командой запуска.

## Минимальные проверки

| Вход | count | min | max | mean |
|---|---:|---:|---:|---:|
| `[10, 20, 30, 40]` | 4 | 10 | 40 | 25.0 |
| `[]` | 0 | `None` | `None` | `None` |
| `[-5, -2, -9]` | 3 | -9 | -2 | -5.333333… |
| `[7]` | 1 | 7 | 7 | 7.0 |
| `[1.5, 2.5]` | 2 | 1.5 | 2.5 | 2.0 |

Для приближённого среднего допускается абсолютная погрешность до `1e-9`. Дополнительно проверь, что исходный список после вызова не поменялся. На этой неделе достаточно простых `assert`; pytest будет позже.
