## Правила изменения статуса

NOT STARTED → IN PROGRESS после начала работы, о котором есть конкретный отчёт. IN PROGRESS → REVIEW после подачи результата. REVIEW → COMPLETED только после PASS: ≥80/100, обязательный результат и понимание подтверждены. REVIEW → FAILED GATE после проверки, выявившей нарушение условий. FAILED GATE → REVIEW после исправлений.

Если данных для оценки недостаточно, оставить REVIEW и запросить недостающее; баллы не выдумывать. Оценку 0 не использовать вместо «пока не проверено». Новая календарная неделя не открывает следующую учебную автоматически.

Для каждого доказательства фиксировать вид проверки: «прочитан код», «запущено наставником», «лог предоставлен учеником», «ответ на защите». Коммит или скриншот без проверки не являются автоматическим PASS. Старые оценки, замечания и результаты пересдач не удалять.
