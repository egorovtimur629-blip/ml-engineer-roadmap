## Техническое задание CLI To-Do

Программа работает в терминале и хранит задачи в памяти текущего запуска. Сохранение в файл относится к теме Week 2 и не требуется для Week 1 Gate.

Понятный начальный вариант: список словарей с `id`, `title`, `done`. Допускается другая простая структура, если ты можешь объяснить выбор.

| Действие | Проверяемое поведение |
|---|---|
| Добавить | Принимает непустое название, создаёт задачу со статусом «не выполнена» и положительным ID. У существующих задач ID различаются. |
| Показать | Для каждой задачи выводит ID, название и статус. Для пустого списка показывает понятное сообщение. |
| Отметить выполненной | Находит задачу по ID и меняет её статус. Другие задачи не меняются. Повторное выполнение сохраняет корректное состояние. |
| Удалить | Удаляет только выбранную задачу. ID оставшихся задач сохраняются. |
| Выйти | Завершает программу штатно. |

Можно сделать меню: 1 — добавить, 2 — показать, 3 — отметить выполненной, 4 — удалить, 0 — выйти. После действия программа снова предлагает меню. Неизвестная команда или ID дают понятное сообщение и не портят список. Пустое название, включая одни пробелы, не создаёт задачу.

Организация кода: отдельные функции для основных действий и отдельное управление меню. Используй modules/imports и базовые type hints осмысленно. Для этой недели достаточно Python и стандартной библиотеки. Git и pytest изучаются на Week 3; сейчас проверки можно описать вручную или оформить простыми assert.
